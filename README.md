## Running
- HTML/CSS/JS: open `src/index.html` in a browser.
- Node/Express: `cd src && npm install && npm start`.
- React: `cd src && npm install && npm run dev`.
- MongoDB projects need a local MongoDB server; set `MONGO_URL` if it is not on the default port.
